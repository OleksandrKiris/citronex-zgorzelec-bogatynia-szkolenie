## Польза и подтверждение

В публичном облачном Chrome на `slownik.html?lang=ua&mode=bogatynia`
поиск `reader` показывает существующую карточку, но смена UA→EN очищает
поле и фильтр. Это наблюдение старой версии, не приёмка нового кода.
Исследованный возможный конфликт раскрытия групп в этом репозитории
не подтвердился по исходникам; соответствующие обработчики не менялись.

Теперь короткий запрос (до 160 символов) сохраняется в параметре `q`.
Смена языка, reload и возврат к сохранённому URL восстанавливают фильтр.
`mode`, hash, остальные параметры и history.state сохраняются; ввод не
создаёт дополнительных шагов Back. Очистка удаляет только `q`.
При запрете History API фильтр работает в памяти, запрос переносится
при смене языка, но reload/Back без обновлённого URL не гарантируется.
Текст присваивается input.value, не вставляется в HTML. Пустой результат
использует существующий перевод и role=status. Нет новых переводов процедур.

## Офлайн и нагрузка

Фильтр использует только существующие локальные данные. Новых сетевых
запросов, runtime-файлов, зависимостей, storage-ключей или миграций нет.
Старый учебный прогресс не меняется. В поиск вводить только учебные термины:
q является частью URL и истории, а не приватным хранилищем.
Первый запуск требует загрузки страницы и существующих PWA-ресурсов по HTTP(S).
На ранее не открывавшем страницу устройстве офлайн-работа не обещается.
Service worker через file:// не заявляется. Внешние ссылки требуют сети.
Фото/аудио не предзагружаются этим изменением.
JS: 221924 → 222830 байт, +906 байт (+197 gzip).
Кэш UI/14 HTML/SW: `20261017-glossary-context1`; другие активы сохраняют URL.
